# 🚗 Car Rental & Vehicle Sharing Management System

A full-stack web application that enables users to rent vehicles online and allows vehicle owners to list their cars for sharing. The platform provides a seamless booking experience with secure authentication, vehicle management, online payments, and location-based search functionality.

## 📌 Project Overview

The Car Rental & Vehicle Sharing Management System is designed to bridge the gap between vehicle owners and renters through a digital platform. It simplifies the traditional vehicle rental process by offering online booking, real-time vehicle availability, secure transactions, and user-friendly management tools.

## ✨ Features

### 👤 User Features
- User Registration and Login
- Search Vehicles by Location
- View Vehicle Details
- Book Vehicles Online
- Secure Payment Processing
- Booking History Management
- Ratings and Reviews

### 🚘 Owner Features
- Add and Manage Vehicle Listings
- Update Vehicle Availability
- Track Bookings
- Manage Rental Requests
- View Earnings

### 🔧 Admin Features
- Manage Users
- Manage Vehicles
- Monitor Bookings
- Platform Analytics
- System Control Dashboard

## 🏗️ System Architecture

The application follows a Three-Tier Architecture:

1. Presentation Layer (Frontend)
2. Business Logic Layer (Backend)
3. Data Layer (Database)

This architecture improves scalability, maintainability, and security.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/car-rental-management-system.git
```

### Navigate to Project Directory

```bash
cd car-rental-management-system
```

### Install Dependencies

```bash
npm install
```

or

```bash
pip install -r requirements.txt
```

### Run Application

```bash
npm start
```

or

```bash
python app.py
```
